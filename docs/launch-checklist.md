# Launch checklist

## Before publishing

- [ ] Run `npm test`.
- [ ] Run `npm run check`.
- [ ] Deploy the static site to a free host.
- [ ] Generate a kit for a fake client and confirm the text looks professional.
- [ ] Test copy buttons in the production browser.
- [ ] Test the Markdown download.
- [ ] Confirm the no-advice disclaimer is visible in the footer and generated Markdown.
- [ ] Open the `templates/` page and confirm every template preview anchor works.
- [ ] Connect the waitlist form or clearly leave it as a placeholder during private testing.

## Minimum launch actions

- [ ] Post a short demo on your LinkedIn or X account.
- [ ] Share in 2 or 3 freelancer communities where self-promotion is allowed.
- [ ] Use the first 10 launch channels document to choose additional channels.
- [ ] Answer comments for the first day, then stop checking daily.
- [ ] Add the URL to any personal website or profile you already control.

## Suggested launch copy

> I built a free client onboarding packet generator for freelancers and small agencies. It creates a welcome kit, access checklist, timeline, kickoff questions, and kickoff email in your browser. No signup, no data storage. Feedback welcome.

## Early feedback questions

- Was the generated packet useful enough to send to a real client?
- What service preset should be added next?
- Would a paid template pack be useful? If yes, what should be inside?
